# Spoken Mobile 产品规格：九键优先的默认输入法 MVP

> 状态：Draft v0.1  
> 日期：2026-08-24  
> 当前目标用户：产品作者本人（个人高频使用优先）

> 阶段说明：本文保留产品目标与验收标准。当前源码已包含触屏九键、单 APK 离线词库、三种语音服务及“场景 × 输出语言”处理；实现边界见 `CONTEXT.md`，真机验收仍需逐项记录，不能以本文或早期 Spike 报告替代。

## 1. 已锁定的产品判断

Spoken Mobile 不是一个需要与其他键盘频繁切换的“语音工具键盘”，而是一款可以长期设为系统默认输入法的完整输入产品。

首版的两个并列核心输入方式是：

1. 中文拼音九键文字输入；
2. 语音输入及按真实使用场景进行的 AI 后处理。

产品必须满足：用户无论方便说话还是只能打字，都不需要离开 Spoken。

## 2. 首版用户与使用环境

### 2.1 核心用户

- 首要用户：产品作者本人；
- 已知输入习惯：日常中文文字输入几乎全部使用拼音九键；
- 常见内容：日常聊天、工作沟通、正式材料、AI 指令、数字与中英文混合内容；
- 设备范围：Android 手机，竖屏单手使用优先。

### 2.2 产品成功的最小定义

满足以下条件，才能称为“默认输入法 MVP”：

- 连续 7 天将 Spoken 保持为默认输入法；
- 日常输入不因缺少基础文字能力而切换到其他输入法；
- 文字输入、语音输入和 AI 处理之间切换时不丢字、不串会话、不提交到错误输入框；
- 密码、验证码、网址、邮箱、数字等特殊输入框可正常完成输入；
- 核心输入过程不依赖网络，网络失败只影响语音识别或 AI 后处理；
- API 密钥、个人词库和输入历史默认只保存在本机安全存储中。

## 3. 产品原则

### 3.1 文字与语音地位平等

语音不是独立页面，文字也不是临时兜底。二者共享当前输入连接、光标、选区和会话上下文。

### 3.2 九键肌肉记忆优先于视觉创新

首版不应先发明新的九键布局。正式定稿前，以用户当前长期使用的九键键盘为基线，逐项对齐：

- 2–9 键字母分布；
- 0、空格、回车、删除、符号和中英文切换的位置；
- 候选词浏览、翻页和选词方式；
- 长按数字、连续删除、按键预览和震动反馈；
- 数字、英文、符号面板的进入与返回路径。

需要用截图和真实任务复刻肌肉记忆，不能只依据设计稿推断。

### 3.3 输入正确性优先于 AI 能力数量

任何异步结果都只能提交到启动该会话时的输入连接。新会话开始、输入框切换、取消或 IME 隐藏后，旧回调必须失效。

### 3.4 核心文字输入离线可用

拼音解码、候选词、用户词频、英文与符号输入均应本地完成。云端能力不能阻塞文字键盘启动。

## 4. MVP 功能范围

### 4.1 P0：中文拼音九键

- 标准 2–9 拼音九键；
- 拼音组合、分词、简拼与常见容错；
- 候选词横向浏览和候选面板展开；
- 单字、词组和整句候选；
- 用户词频学习及本地用户词库；
- 联想下一词；
- 简体中文输出；
- 删除未完成拼音、撤销已选分段、删除已提交文字；
- 长按连续删除；
- 空格、逗号、句号、回车/发送；
- 按键震动和按键预览，并允许关闭。

### 4.2 P0：辅助布局与输入框适配

- 英文字母布局；
- 数字布局；
- 中文及英文符号面板；
- 邮箱、网址、电话、数字、小数和搜索输入框适配；
- 密码框禁用候选学习、语音入口、剪贴板建议和敏感预览；
- `EditorInfo` 对应的回车、发送、搜索、下一项、完成动作；
- 横屏最低可用，但首版不以横屏体验为优化重点。

### 4.3 P0：语音输入

- 九键主界面随时可触达的麦克风入口；
- 点击开始、点击停止、显式取消；
- 实时转写预览；
- 每次录音使用独立会话；
- 建连前缓存音频，断线时有界重试；
- 停止后等待最终结果，超时使用最新可靠部分结果；
- 语音结果插入当前光标位置；
- 完成后立即回到九键文字编辑状态；
- 失败后保留原输入内容，用户可直接继续打字。

### 4.4 P0：场景化 AI 处理

继承桌面端已经验证的“文字最终用在哪里”模型：

- 原样转写；
- 日常聊天；
- 工作沟通；
- 正式材料；
- 会议记录；
- 内容分享；
- AI 指令。

输出语言与场景解耦：原语言、英文、日文、韩文。MVP 界面只需暴露最近使用和原样转写，其余场景进入二级面板，避免挤占九键主界面。

### 4.5 P0：基础编辑

- 光标左右移动；
- 选区存在时替换选中文字；
- 撤销本次语音或 AI 提交；
- 对当前未提交的语音结果继续打字修正；
- 输入框切换时清理 composing 状态并终止旧会话。

### 4.6 P1：MVP 后验证

- 剪贴板历史；
- 常用短语；
- 更完整的文本选区工具；
- 个性化词库导入/导出；
- 根据当前 App 建议使用场景；
- 对选中文字执行润色、翻译或改写；
- 全键拼音作为可选布局。

### 4.7 首版明确不做

- 字迹手写识别；
- 拼音双键/全键以外的多种中文方案；
- 滑行输入；
- 九宫格以外的大量主题和布局市场；
- 云端同步用户完整输入历史；
- 强制修改系统默认输入法或自动切回 Spoken。

注：ASR 供应商决策已更新——首版保留 Qwen 实时、讯飞听写、自定义（Whisper
兼容批量）三家引擎，由用户在「语音与 AI」设置中选择，不再属于"不做"项。

## 5. 核心界面结构

键盘常态由四层组成：

```text
候选栏：候选词 / 展开候选 / 当前拼音
工具栏：场景入口 / 语音入口 / 编辑与更多
主键区：拼音九键
底部操作区：符号 / 中英或数字 / 空格 / 回车 / 删除
```

约束：

- 麦克风入口在九键常态下始终一击可达；
- 开始语音不应切换成无法继续打字的独占页面；
- 录音中九键可以暂时降噪或收起，但取消、停止和当前转写必须可见；
- 语音完成后无需额外确认即可继续打字，是否自动提交由后续原型验证；
- AI 场景不占据固定大面积键位。

## 6. 统一输入会话模型

```text
Idle
 ├─ 按九键 → ComposingText → 选词/空格 → Committed
 └─ 点麦克风 → VoiceStarting → VoiceRecording
                     ├─ 取消 → Idle
                     └─ 停止 → Recognizing → 可选 AIProcessing → ReviewOrCommit
                                                          ├─ 取消 → Idle
                                                          └─ 提交 → Committed
```

每个会话必须持有：

- `sessionId`；
- 启动时的输入连接身份；
- 输入框类型与隐私标志；
- 初始光标/选区快照；
- 当前 composing 文本；
- ASR、AI 和超时任务；
- 是否仍允许提交的原子状态。

以下事件必须使旧会话失效：

- 用户取消；
- `onFinishInput` 或 `onFinishInputView`；
- 新输入连接绑定；
- 新语音会话开始；
- 输入法服务销毁；
- ASR/AI 配置切换。

## 7. 关键交互验收场景

### 7.1 九键输入

1. 输入常用聊天句子并选词；
2. 输入人名、品牌名和中英文混合词；
3. 删除一个拼音数字、撤销一个已选词、连续删除正文；
4. 输入数字、手机号、邮箱、网址和验证码；
5. 在微信、浏览器、备忘录、飞书和 AI 对话框中验证回车动作。

### 7.2 语音与文字连续编辑

1. 九键输入开头，语音补充中段，再用九键修改结尾；
2. 录音中取消，输入框不得残留转写；
3. 识别或 AI 处理中切换输入框，结果不得进入新输入框；
4. 网络断开后语音失败，九键必须继续可用；
5. 连续执行 100 次短录音，不串结果、不占用旧麦克风会话。

### 7.3 隐私与安全

1. 密码框不展示语音、候选学习及剪贴板建议；
2. API Key 不写入普通偏好、日志和系统备份；
3. 本地指标只记录耗时、成功、失败与重试，不记录正文和音频；
4. 用户可以清除个人词库、个人背景和本地指标。

## 8. 性能与质量门槛

- 键盘热启动无可感知等待；
- 按键反馈不依赖主线程之外的网络或磁盘任务；
- 本地候选首屏目标：普通输入设备上 P95 小于 50 ms；
- 录音入口点击后立即显示确定状态，不允许无反馈；
- Crash-free session 目标不低于 99.9%；
- 所有异步会话、候选提交和输入框切换必须有自动化回归测试；
- 发布构建必须通过单元测试、Lint 和核心实机冒烟测试。

## 9. 第一轮原型需要回答的问题

1. 当前常用九键键盘的具体布局与长按习惯是什么？
2. 麦克风放在工具栏、空格键附近还是独立大按钮，哪一种最不破坏九键肌肉记忆？
3. 语音完成后应自动提交，还是先保持 composing 供九键修改？
4. 候选栏与实时转写是否能共用同一区域？
5. 场景选择是录音前选择、录音后选择，还是记忆上次场景？
6. 一周实际使用中，仍然切换到其他键盘的原因和频率是什么？
