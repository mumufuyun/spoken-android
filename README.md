# Spoken Android

Spoken 是一款将中文拼音九键、语音输入和 AI 文本处理放在同一键盘中的 Android 输入法，基于 Fcitx5 for Android 与 Rime 开发。

当前源码版本为 **1.0.0**。源码中已有功能不等于已完成真机验收；发布包及版本说明以[本仓库 Releases](https://github.com/mumufuyun/spoken-android/releases)为准。早期底座测试记录见 `docs/spoken/OPEN_SOURCE_BASELINE_REPORT.md`，不能作为当前版本的测试结果。

## 核心功能

- 触屏中文拼音九键、拼音消歧、候选展开、本地词库与联想。
- 英文 QWERTY、数字、符号及输入框对应的回车动作。
- 键盘内点击开始、点击停止的语音输入；支持 Qwen 实时、讯飞听写和自定义 Whisper 兼容接口。
- 原样转写直接输出识别原文；另有流畅转写、日常聊天、工作沟通、正式材料、会议记录、内容分享、AI 指令 7 个 AI 整理场景。
- 场景与输出语言独立选择：原语言、英文、日文、韩文。AI 失败或识别不完整时保留原文并提示，处理中可点击语音键跳过 AI。
- Rime 引擎和基础词库内置于同一个 APK，首次中文输入不需要联网。

保留底座的实体九键、笔画、注音、手写和工具栏能力；实体按键规则见下文。触屏英文使用 QWERTY，实体英文九键使用 multi-tap 或 T9 联想。

## 下载与安装

1. 在[本仓库 Releases](https://github.com/mumufuyun/spoken-android/releases)选择已发布的签名 APK。没有发布包时，需要从源码构建。
2. 按设备架构选择 `com.spoken.android-版本-arm64-v8a-release.apk` 或 `com.spoken.android-版本-armeabi-v7a-release.apk`，每台设备只安装其中一个。无需另装 Rime 插件或手动复制词库。
3. 打开 Spoken，按引导启用并选择输入法。首次打开文本框时，等待内置中文词库完成准备。
4. 需要语音时，在「语音与 AI」中配置服务及凭据，并允许麦克风权限。语音配置不影响离线文字输入。

语音识别与 AI 处理会访问所配置的服务。API 密钥通过 AndroidKeyStore 加密保存，并从系统备份中排除。切换输入框或隐藏键盘会取消当前语音会话。

长按触屏语音键可选择场景与语言、取消本次语音，或插入上次识别原文。找回仅限当前输入框、2 分钟内，切换输入框或收起键盘即清除，不保存输入历史。自定义 Whisper 兼容服务在停止录音后上传音频，不提供实时转写。

应用更新指向本仓库；词库配置更新仍来自 [rime-ice-t9-phone](https://github.com/Rizumu85/rime-ice-t9-phone)。Debug 包为 `com.spoken.android.debug`，与正式包独立安装。

## 实体九键按键规则

### 中文：拼音、笔画与注音

在设置首页【中文输入方案】选择需要保留的方案，并分别设置默认简繁。启用多个方案后，空闲时长按 `*` 按“拼音 -> 笔画 -> 注音”循环；完整 Rime 方案输入法的快捷设置里【词库切换】进入。

| 按键 | 拼音九键 | 笔画九键 | 注音九键 |
| :--- | :--- | :--- | :--- |
| `1` | 拼音分词符号 `'` | 横 `一` | ㄅㄆㄇㄈ |
| `2` | ABC | 竖 `丨` | ㄉㄊㄋㄌ |
| `3` | DEF | 撇 `丿` | ㄍㄎㄏ |
| `4` | GHI | 点/捺 `丶` | ㄐㄑㄒ |
| `5` | JKL | 折 `乛` | ㄓㄔㄕㄖ |
| `6` | MNO | 未知笔画 `？` | ㄗㄘㄙ |
| `7` | PQRS | 不输入笔画 | ㄚㄛㄜㄝ |
| `8` | TUV | 不输入笔画 | ㄞㄟㄠㄡ |
| `9` | WXYZ | 不输入笔画 | ㄢㄣㄤㄥㄦ |
| `0` | 有候选时确认；空闲时空格 | 有候选时确认；空闲时空格 | ㄧㄨㄩ |

共同规则：

- 短按 `*` 打开中文符号，再按一次切换中英文符号。
- 符号第一页末尾的 `↵` 在支持的聊天输入框中发送消息，在其他输入框中插入换行。
- 输入编码时短按 `#` 提交上方显示的拼音、笔画或注音；空闲时短按 `#` 执行回车或搜索。
- 长按 `#` 切换中文、英文和数字模式。
- 有候选时长按 `1..9,0` 选择第 1 至 10 个候选；无候选时输入对应数字。
- OK/确认键提交当前候选。注音的 `0` 是输入键，因此使用 OK 确认。
- 拼音可以直接连续输入每个数字键默认显示的声母来组句；非默认声母以及 `zh`、`ch`、`sh` 可先在拼音筛选行确认，再继续输入。

默认简繁只在进入方案时应用一次；当前会话仍可通过 Rime 快捷选项临时切换。

在输入法上方【⋯】快捷设置中启用【联想中文】后，提交汉字候选会继续显示下一段文字建议。可用方向键与 OK 选择，也可长按 `1..9,0` 快速选择；拼音和笔画模式还能短按 `0` 确认。退格会先关闭联想候选，不会删除已经输入的文字。中文模式下【联想中文】会占用英文模式【联想英文】的同一个快捷设置位置。

### 英文

普通英文九键使用 multi-tap。在输入法上方【⋯】快捷设置中启用【联想英文】后，数字序列会预测单词，并在提交后继续显示下一词候选。

| 按键 | 短按 | 长按 |
| :--- | :--- | :--- |
| `1` | 切换 `abc / Abc / ABC` | 数字 1 / 第 1 个候选 |
| `2..9` | 对应字母组 | 对应数字 / 第 2 至 9 个候选 |
| `*` | 英文标点 | 字面量 `*` |
| `0` | 空格或确认候选并加空格 | 数字 0 / 第 10 个候选 |
| `#` | 提交当前英文后回车或搜索 | 切换中文、英文、数字模式 |

#### 学习新单词

1. 暂时关闭【联想英文】，用普通英文九键输入完整单词。
2. 用空格、标点或回车结束单词。
3. 再启用【联想英文】，输入对应数字序列即可看到新候选。

只学习两个字母以上的纯英文词；密码框和禁止个性化学习的输入框不会记录。误学内容可在【输入方式】→【词库与学习】→【联想英文词库】中搜索、编辑或删除。

### 数字

| 按键 | 短按 | 长按 |
| :--- | :--- | :--- |
| `1` | 1 | `-` |
| `2` | 2 | `+` |
| `3` | 3 | `=` |
| `4` | 4 | `π` |
| `5` | 5 | `/` |
| `6` | 6 | `≈` |
| `7` | 7 | `(` |
| `8` | 8 | `%` |
| `9` | 9 | `)` |
| `*` | `*` | 显示运算符提示 |
| `0` | 0 | `.` |
| `#` | 回车或搜索 | 切换中文、英文、数字模式 |

输入算式后长按 `3` 输入 `=`，或长按 `6` 输入 `≈`，可显示简单计算结果；按 OK/回车确认结果。

## 辅助输入

### 手写输入

在工具栏设置中启用【手写输入】后，可从输入法工具栏进入手写托盘：

- 中文手写无需下载即可使用内置离线识别；在【输入方式】中可另行下载 ML Kit 中文增强模型。提交汉字后会继续提供中文联想候选。
- 英文手写需要先下载 ML Kit 英文模型，下载完成后可完全离线使用；开启【联想英文】时也会提供英文预测候选。
- 支持钢笔和毛笔笔触、撤销笔画、候选确认、中文读音提示，以及表情、数字、符号、空格、逗号和回车等常用操作。
- 手写候选可用方向键移动、OK 或 `0` 确认；实体键 `1/4/7/*` 分别进入表情、数字、切换中英文手写和符号，`3/6/9` 分别执行退格、空格和逗号。

识别模型只需主动下载一次；下载失败可以在【输入方式】中重试，打开手写面板本身不会自动联网。

### 选区模式

长按 OK/确认键进入选区模式，用方向键扩展选区，再按 OK 打开操作面板：上复制、左剪切、右粘贴、下删除；返回或删除键取消。

### 密码模式与按键音

- 密码框会尽量自动切换到全键盘，也可从【⋯】手动开启密码模式。
- 输入预览和窥探功能可处理被键盘遮挡的密码框或验证码。
- 按键音支持内置声音和手动导入百度输入法 Android `.bds` 皮肤里的按键音；导入后可预览、改名、切换和删除。
- 在【按键与工具栏】中启用【完整物理按键音】后，文本框外的返回、菜单、接听和挂断键也会播放所选音效；轻量无障碍服务只观察这些按键，不读取屏幕内容。
